# Retail Sales Analytics

## Project Overview
An end-to-end retail sales analysis project using the UCI Online Retail II dataset. This project explores sales performance, product revenue, and country-wise revenue to generate useful business insights.

## Objectives
- Clean and prepare retail transaction data.
- Calculate key performance indicators (KPIs).
- Analyze monthly revenue trends.
- Identify top-performing products and countries.
- Provide actionable business recommendations.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Key Results
- **Cleaned transactions:** 524,879
- **Total revenue:** £10,642,128.80
- **Unique invoices:** 19,960
- **Unique customers:** 4,338
- **Unique products:** 3,922
- **Average revenue per invoice:** £533.17

## Visualizations
1. Monthly Revenue Trend
2. Top 10 Products by Revenue
3. Top 10 Countries by Revenue

## Dataset
UCI Machine Learning Repository — Online Retail II.

The notebook loads the 2010–2011 transaction sheet directly from the dataset source.

## Methodology
1. Load and inspect the dataset.
2. Identify missing values and duplicate records.
3. Remove duplicate rows, cancelled invoices, and invalid sales transactions.
4. Calculate revenue using quantity multiplied by unit price.
5. Analyze KPIs and visualize sales trends.
6. Summarize findings and business recommendations.

## Conclusion
The analysis demonstrates how Python-based data analytics can help businesses understand sales performance, identify high-revenue products and markets, and improve inventory planning and customer-retention strategies.

**Note:** This analysis uses historical 2010–2011 data. Revenue figures reflect the cleaning rules applied in the notebook.
